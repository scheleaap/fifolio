2 · Constraints

Anything that limits design freedom. Some constraints are imposed from outside (the law, the brokers' file formats); others are the owner's standing choices, which are negotiable but not casually.

2.1 External constraints

Imposed by the domain. The design cannot negotiate these.

2.3 Organizational constraints

ConstraintBackgroundRefs
Specification firstBehavior is decided in design/ before it is built. A new broker type is specified first and imported afterwards. It is never inferred from data.DEC-019
Requirement identifiersEvery testable statement carries a stable id that is never reused. Tests name the ids they cover, so coverage of the specification can be checked.design/README.md
Undecided means blockedopen-questions.md is the authoritative, hand-maintained list of what is undecided. Work items touching a listed requirement are not implemented until it is answered.open-questions.md
Decisions are append-onlyA decision entry is never edited. A reversal is a new entry that cites the old one.decisions.md
Agent-driven development cycleSpecialized agents run the cycle: spec-auditor, planner, implementer, conformance-reviewer, test-reviewer. Reviewers never write code, fix loops are bounded to three rounds, and commits happen only after a clean pass..claude/agents/README.md
CI gatesfmt, clippy with -D warnings, and tests. Coverage thresholds of 95 / 90 / 75 per crate (core / server / cli) apply to changed lines.TST-024 TST-025 DEC-023
Every change ships with testsUnit tests for logic, integration tests for storage and HTTP, end-to-end tests for user paths. A bug fix starts with a failing test.CLAUDE.md testing.md

2.4 Conventions

  • Rounding is half away from zero. It is done by the caller before a storage or presentation boundary, and storage refuses a value that is not at its scale. ARC-010 DEC-067
  • Machine-readable output uses ISO 8601 dates and dot decimals, whatever the interface language. CLI-028
  • Declare once, cite elsewhere. A bracketed id declares a requirement exactly once. Prose elsewhere cites it without brackets. design/README.md
